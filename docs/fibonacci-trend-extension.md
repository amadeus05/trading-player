# 📊 Fibonacci Trend-Based Extension

## Описание

Инструмент **Fibonacci Trend-Based Extension** предназначен для построения уровней расширения Фибоначчи на основе трех точек:

1. **Точка 1**: Начало тренда (swing low/high)
2. **Точка 2**: Конец тренда (swing high/low)
3. **Точка 3**: Точка коррекции/отката

От точки 3 откладываются уровни расширения Фибоначчи, рассчитанные на основе расстояния между точками 1 и 2.

## Уровни расширения

Инструмент использует следующие уровни Фибоначчи:

- **0.000** - Базовый уровень (серый)
- **0.236** - 23.6% (красный)
- **0.382** - 38.2% (оранжевый)
- **0.500** - 50.0% (зелёный)
- **0.618** - 61.8% (бирюзовый)
- **0.786** - 78.6% (голубой)
- **1.000** - 100% (серый)
- **1.272** - 127.2% (синий)
- **1.618** - 161.8% (синий)
- **2.618** - 261.8% (тёмно-красный)
- **3.618** - 361.8% (фиолетовый)
- **4.236** - 423.6% (красный)

## Как использовать

### Создание инструмента

1. Нажмите на кнопку инструмента Fibonacci Trend-Based Extension на панели инструментов (иконка с зигзагообразной линией)
2. Кликните на графике, чтобы установить **первую точку** (начало тренда)
3. Кликните, чтобы установить **вторую точку** (конец тренда)
4. Кликните, чтобы установить **третью точку** (точка коррекции)

### Редактирование

- **Перемещение точек**: Кликните и перетащите любую из трех точек-маркеров
- **Перемещение всего инструмента**: Кликните и перетащите трендовую линию или любой уровень
- **Блокировка**: Нажмите на иконку замка в панели инструмента, чтобы заблокировать/разблокировать инструмент

### Настройки

В плавающей панели инструмента доступны следующие настройки:

- **Толщина линии**: 1px, 2px, 3px, 4px
- **Стиль линии**: Solid (сплошная), Dashed (пунктирная), Dotted (точечная)
- **Блокировка**: Предотвращает случайное редактирование
- **Удаление**: Удаляет инструмент с графика

### Горячие клавиши

- **Escape**: Отменить создание инструмента или снять выделение
- **Delete/Backspace**: Удалить выбранный инструмент

## Формула расчёта

Для каждого уровня расширения `ratio`:

```
levelPrice = price3 + (price2 - price1) × ratio
```

Где:
- `price1` - цена в точке 1
- `price2` - цена в точке 2
- `price3` - цена в точке 3 (откуда строятся уровни)

## Применение в трейдинге

Fibonacci Trend-Based Extension используется для:

1. **Определения целей движения** после коррекции
2. **Поиска уровней take profit** в направлении тренда
3. **Анализа силы импульсного движения**
4. **Определения зон перекупленности/перепроданности**

## Примеры использования

### Восходящий тренд

1. Точка 1: Локальный минимум (начало роста)
2. Точка 2: Локальный максимум (вершина роста)
3. Точка 3: Точка коррекции вниз

Уровни расширения покажут потенциальные цели для следующего импульса вверх.

### Нисходящий тренд

1. Точка 1: Локальный максимум (начало падения)
2. Точка 2: Локальный минимум (дно падения)
3. Точка 3: Точка коррекции вверх

Уровни расширения покажут потенциальные цели для следующего импульса вниз.

## Отличие от Fibonacci Retracement

| Характеристика | Retracement | Trend-Based Extension |
|----------------|-------------|----------------------|
| Количество точек | 2 | 3 |
| Назначение | Откаты в тренде | Расширение движения |
| Направление | Коррекция | Продолжение тренда |
| Типичные уровни | 0-100% | 0-400%+ |
