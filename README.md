# Candle Lab

Локальный replay-терминал для тренировки торговли без доступа к будущим свечам.

## Запуск

```powershell
npm install
npm run dev
```

Откройте `http://localhost:5173`. Встроен демонстрационный набор BTCUSDT. Дополнительные рынки можно загрузить через меню истории в шапке.

Сделки, разметка и настройки сохраняются локально в `data/state.json`.
